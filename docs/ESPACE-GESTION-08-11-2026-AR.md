# مساحة الإدارة المختصرة

## المنتجات

اضغط رقم **Ordre** واختر الموضع المطلوب داخل العائلة، ثم **Déplacer et fixer**. لا توجد أسهم تحريك أو سحب في قائمة المنتجات.

- **Auto** مفعّلة: يتبع المنتج الفرز التلقائي بالمرجع، مع الأطقم في آخر نوعها.
- **Auto** غير مفعّلة: يحتفظ المنتج بالموضع الذي اخترته. أعد تفعيلها لإرجاعه للفرز التلقائي.

اضغط صورة المنتج، أو الصورة الفارغة، لفتح **Photos du produit** مباشرة. يمكنك رفع PNG أو JPG أو WebP، وضبط التكبير والموضع وترتيب الصور، ثم **Enregistrer les photos**. هذا الحفظ يغيّر الصور فقط ويحتفظ بالسعر والوزن والعائلة والموضع وبقية المعلومات الحالية.

زر القلم يفتح إعدادات المنتج الكاملة. عند اختيار الصفحة التالية أو السابقة تصعد القائمة إلى أول منتج فيها.

## الإعدادات

تبدأ **Réglages** بواجهة أقسام. افتح الموضوع المطلوب مثل **Thèmes** أو **Sécurité** أو **Mise à jour**. لكل موضوع صفحته، ويمكن الرجوع عبر **Tous les réglages**.

على الهاتف، استعمل قائمة **Rubrique** لاختيار القسم. تبقى التعديلات غير المحفوظة أثناء التنقل بين الأقسام؛ اضغط **Enregistrer les réglages** لحفظها. إذا كان حقل مطلوب ناقصًا، تنتقل الإدارة إلى صفحته لتصحيحه.

مساحة الإدارة تستعمل الشاشة للعمل دون رأس المتجر وتذييله. يبقى **Voir le magasin** للرجوع إلى الموقع، و**Se déconnecter** للخروج من الإدارة.

هذا التحديث لا يحتاج إلى إعادة تثبيت المتجر، ولا يستبدل الصور أو بيانات الموقع الموجودة.
