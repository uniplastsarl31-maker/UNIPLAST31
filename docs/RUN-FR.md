# RUN.BAT — nouvelle version

Extrayez toute l’archive : RUN.BAT, server et les fichiers de l’interface doivent rester ensemble. Node.js **22.18+** est requis. Choisissez 1 pour ouvrir la boutique et 0 pour arrêter son propre serveur. Au premier accès à Espace de gestion, choisissez votre mot de passe administrateur.

Les données sont conservées dans **.uniplast-data**. Sauvegardez ce dossier entier après fermeture et ne le diffusez pas. Les choix 2/3 nécessitent les sources et reconstruisent le programme ; quittez puis redémarrez pour charger le nouveau code serveur. Le choix 4 ouvre uniquement les fichiers locaux ; il ne publie pas le magasin.

Guide : [UTILISATION-FR.md](UTILISATION-FR.md). Le lanceur local ne synchronise pas sa base avec Internet. Le site web nécessite une configuration Supabase distincte.
