# Fonctions de la nouvelle version

| Fonction | Livré |
| --- | --- |
| Présentation | Texte plus grand, couleurs UNIPLAST, interface française adaptée au mobile |
| Promotions | Cadre rouge épais, pourcentage et prix agrandis, dates contrôlées par le serveur |
| Diaporamas | Accueil et chaque famille, import d’images, zoom, recadrage, positions, hauteur, durée et ordre |
| Entreprise | Présentation éditable, section d’accueil et page Qui sommes-nous ? |
| Suggestions | Sans inscription, messages privés dans l’administration, suivi nouveau/lu/archivé |
| Accès client | Téléphone + code de 6 chiffres créé et modifiable par le responsable, sans inscription |
| Gestion | Mot de passe indépendant choisi au premier démarrage local, modifiable dans Réglages |
| Conservation locale | SQLite : produits, réglages, fichiers, codes hachés, commandes, demandes et suggestions |
| Documents | Instantanés des prix, historique lié à l’accès client, PDF et partage manuel, reprise de panier |
| Catalogue | 350 références / 17 familles, recherche, filtres et codes-barres |
| Saisons | Ramadan/Été, dates choisies et recommandations selon ventes confirmées |
| Contacts | Téléphones, WhatsApp, Facebook, site et PDF public administrables |
| Internet | Adaptateur Supabase et migrations 001–003 fournis ; projet du propriétaire à configurer |

RUN.BAT utilise une base locale réelle. Le lien web sans Supabase configuré reste une prévisualisation annoncée et sans prix importés. Pas de synchronisation automatique entre les deux modes, pas de paiement en ligne ni d’envoi automatique à des tiers.
