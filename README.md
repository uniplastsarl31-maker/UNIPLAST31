# UNIPLAST — متجر بالفرنسية مع حفظ محلي فعلي

الكتالوج الأصلي: **350 منتجًا و17 عائلة**. تصميم أوضح ومتجاوب، تخفيضات بارزة، سلايدر للرئيسية ولكل عائلة، تعريف بالشركة واقتراحات الزبائن.

## التشغيل

فك الضغط كاملًا، شغّل **RUN.BAT** واختر **1**. أبقِ مجلد server بجانبه، ومعه dist في المشروع الكامل أو index.html وassets في النسخة الجاهزة. يلزم Node.js **22.18 أو أحدث**، ويمكن استخدام نسخة Node الموجودة مع Codex.

افتح **Espace de gestion** أسفل الموقع. في أول مرة تختار كلمة مرور المسؤول بنفسك (12 حرفًا على الأقل). لا توجد كلمة مرور افتراضية. من **Clients agréés** تضيف الهاتف ورمزًا من ستة أرقام للزبون ثم تنسخ رسالة الدخول أو تجهّز مشاركتها في Viber. الزبون يدخل بالهاتف والرمز فقط، دون إنشاء حساب أو تفعيل بريد.

التعديلات والرموز والطلبات والصور والاقتراحات تُحفظ فعلًا في **.uniplast-data** وتبقى بعد إغلاق البرنامج. الرموز محمية بالتجزئة والملح ولا تظهر في قائمة الزبائن. تغيير الرمز أو تعطيل الزبون يلغي جلساته السابقة. كلمة مرور المسؤول مستقلة وتتغير من الإعدادات.

السلايدر والصور وارتفاعها وحجم عرضها ومدة الانتقال في **Réglages**، وكذلك **Qui sommes-nous ?**. الاقتراحات في **Suggestions clients**. دليل مفصّل: [docs/UTILISATION-FR.md](docs/UTILISATION-FR.md).

## الحفظ والتشغيل

أوقف البرنامج بالخيار **0**، ثم انسخ .uniplast-data كاملًا إلى نسخة احتياطية خاصة. لا ترسله للزبائن. الأرشيف المرفق خالٍ من قواعد الاختبار وكلمات المرور والزبائن التجريبيين. ملف BAT وحده لا يكفي : أرسل البرنامج كاملًا. الخياران **2 و3** يعيدان البناء ويحتاجان مصادر المشروع؛ بعد تعديل كود الخادم أوقف البرنامج وأعد تشغيله. الخيار **4** يفتح ملفات الواجهة المحلية فقط، ولا ينشر قاعدة البيانات.

لا تتضمن البيانات تخفيضات أو مبيعات أو توفرًا مختلقًا. 34 منتجًا دون سعر والتوفر يحتاج تأكيد المدير. السعر للوحدة TTC والشراء بالكرتونة؛ الكمية والأسعار والمخزون تُراجع على الخادم. تحتفظ الفواتير بأسعارها القديمة، ويمكن إعداد PDF ومشاركته يدويًا. لا يوجد دفع إلكتروني.

## البناء والاختبار

اختُبر على Node.js 24.19.0 وpnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm test:local
pnpm test:database
```

build يولّد واجهة النسخة المحلية في dist والملفات الخاصة بالخادم في server/generated. لا تُضمّن أسعار الكتالوج في حزمة الواجهة المحلية. شغّل بـ RUN.BAT؛ خادم Vite للملفات وحده لا يشغّل قاعدة البيانات.

## النسخة المشتركة على الإنترنت

النسخة المحلية تستمع على الكمبيوتر فقط. عنوان **127.0.0.1 ليس رابطًا للزبائن**، وقاعدة الكمبيوتر ليست متزامنة مع الموقع المنشور. لمشاركة البيانات على الهواتف يلزم إعداد خدمة الاستضافة.

دعم Supabase مرفق:

1. شغّل migrations بالترتيب: 001_store.sql ثم 002_customer_features.sql ثم 003_pin_and_presentation.sql، ثم supabase/seed-catalog.sql للاستيراد الأول فقط. لا تعِد زرع الكتالوج فوق بيانات العمل.
2. فعّل Anonymous Sign-Ins للجلسات الخلفية للزبائن (لا تظهر شاشة تسجيل لهم). أنشئ مستخدم المسؤول في Auth وأضف معرّفه إلى public.admin_users. الإدارة بالبريد وكلمة المرور والزبائن بالهاتف والرمز.
3. في .env ضع VITE_SUPABASE_URL ومفتاح publishable/anon فقط في VITE_SUPABASE_ANON_KEY. لا تضع service_role أو sb_secret أو كلمة مرور قاعدة البيانات في المتصفح.
4. شغّل **pnpm build:web** وانشر **out**. اختبر Auth وStorage والسياسات والاتصال في الاستضافة قبل افتتاح المتجر.

دون الربط يولّد build:web **معاينة تصميم معلنة** بكتالوج منقّح بلا الأسعار الأصلية. لا تحفظ هذه المعاينة الأكواد ولا تستقبل أوامر فعلية. أكواد وصور النسخة المحلية لا تُنقل تلقائيًا إلى Supabase. حالة النشر في docs/DEPLOYMENT-STATUS.md، والتحقق في docs/VERIFICATION.md. الصور والشعار الأصليان محفوظان؛ مصادر الأصول في docs/asset-sources.json.
